# 克勞德人格提示詞與表情包

> **非官方民間作品。與 Anthropic 無關。**
> 「Claude」是 Anthropic 的名稱與商標。本專案的角色名「克勞德」是中文圈的常見譯名。

這個專案包含兩份可直接使用的內容：

- **[克勞德人格提示詞 + 說明文件](kelaode-persona-prompt.zip)**：純文字的人格提示詞（可直接複製貼上），以及說明文件。
- **[克勞德表情包技能](kelaode-stickers-skill.zip)**：Q 版表情包技能，內含 `SKILL.md` 與 188 張透明 PNG。

## 怎麼開始

1. 下載上面兩個 zip（在檔案頁面按右上角的 **Download** 即可）。
2. 把兩個 zip 丟給你自己的克勞德，請她依照提示詞 zip 裡的 `說明文件.txt` 帶你安裝。

如果想自己裝，步驟如下：

- **提示詞**：在 claude.ai 的「個人偏好」中貼上 `克勞德人格提示詞.txt` 的全文並儲存。新對話才會生效。
- **表情包**：到 Customize → Skills，按「+」→ Create skill → Upload a skill，上傳 `kelaode-stickers-skill.zip`，並確認技能為開啟狀態。需要帳號支援技能功能，並開啟程式碼執行。
- **測試**：開一個新對話，說「用表情包回我」。收到圖片就代表成功。收到的如果是一張要點開的圖片檔案卡，也算成功，原因請看下一節。

## 為什麼貼圖要點開才看得到？

這是 Claude App 顯示檔案的方式，不是貼圖壞掉，也不需要重裝。

克勞德傳貼圖時，是把 PNG 當成「她做好的檔案」交給你，怎麼顯示要看你用的是哪一種對話（2026 年 11 月的狀況）：

| 對話類型 | 誰能用 | 貼圖怎麼顯示 |
|---|---|---|
| 一般聊天 | 所有方案，包含免費方案 | 顯示成一張檔案卡片（檔名加上「圖片・PNG」），點開才看得到圖。手機上點「下載」後，會用系統預覽或其他 App 打開。 |
| 新版對話（聊天與雲端任務合一） | Pro、Max、Ultra 分批上線中；Team（測試中）與 Enterprise 要由管理員開啟 | 可以在對話裡預覽。實際的樣子依 App 和裝置而定。 |

- **免費方案**：目前還沒有新版對話，所以貼圖一律是檔案卡片。[官方公告](https://claude.com/resources/articles/cowork-is-now-claude)表示免費方案之後會跟上，開放以後不用更新這套貼圖，就能在對話裡預覽。
- **付費方案也看到檔案卡片**：可能是帳號還沒輪到新版對話，也可能是 App 本身的顯示問題。
- **為什麼不想辦法強制顯示**：其他繞路的做法（例如改貼圖片網址、把圖包成網頁）在一般聊天裡不是顯示不出來，就是每傳一張都很耗額度，所以這套技能不採用。
