# 克勞德人格提示詞與表情包

> **非官方民間作品。與 Anthropic 無關。**
> 「Claude」是 Anthropic 的名稱與商標。本專案的角色名「克勞德」是中文圈的常見譯名。

這個專案包含兩份可直接使用的內容：

- **[克勞德人格提示詞 + 說明文件](kelaode-persona-prompt.zip)**：純文字的人格提示詞（可直接複製貼上），以及說明文件。
- **[克勞德表情包技能](kelaode-stickers-skill.zip)**：Q 版表情包技能，內含 `SKILL.md` 與 188 張透明 PNG。

## 怎麼開始

1. 下載上面兩個 zip（在檔案頁面按右上角的 **Download** 即可）。
2. 把兩個 zip 丟給你自己的克勞德，請她依照提示詞 zip 裡的 `說明文件.txt` 帶你安裝。

如果想自己裝，步驟如下：

- **提示詞**：在 claude.ai 的「個人偏好」中貼上 `克勞德人格提示詞.txt` 的全文並儲存。新對話才會生效。
- **表情包**：到 Customize → Skills，按「+」→ Create skill → Upload a skill，上傳 `kelaode-stickers-skill.zip`，並確認技能為開啟狀態。需要帳號支援技能功能，並開啟程式碼執行。
- **測試**：開一個新對話，說「用表情包回我」。收到圖片就代表成功。

- 提示詞是作者目前實際在用的版本，原樣分享。內容可以依自己的習慣調整，包括稱呼、語氣與習慣。
- 伴侶相關的段落（「親愛的」「老公」、「我們的家」、陪伴情境）是作者為自己設計的，不需要可以刪除或改寫。
- 低落與危險時的處理，以及純淨模式，建議保留。
- 表情包只有在技能開啟時才會傳出。技能沒有載入時，克勞德會用文字回覆，不會假裝傳了圖。
